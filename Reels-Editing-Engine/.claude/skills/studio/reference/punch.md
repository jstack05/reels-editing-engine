# punch: dial an element up (bolder)

Load `craft-floor.md` and `scale.md` first. `punch` makes something bolder: bigger, more presence, more
impact. Usually per element (`/studio punch hook` = a bigger hook). It is the creator's opt-in way to bring
one thing up. Reaching for more effects is the opposite of bold; punch is about conviction in the ONE move.

## What it does

- **Targets one role** (hook, caption, takeover, thought) and steps its size or presence UP, in the pack's
  relative terms (a larger multiplier over the role's base, see `scale.md`).
- Holds the hierarchy: punching the caption should not let it out-shout the hook. Bring the target up to the
  conviction its role allows, not past it.
- Holds the floor, hard: bigger must still fit. It never pushes text off screen or onto the face. If a punch
  would break the safe zone, stop at the largest size that clears it and say so.

## The move

Bring the target up one confident step, look, and stop when it lands. One step at a time. Bolder is precision,
not maximalism, so amplify the one thing and let the rest hold.

## Per path (from `fidelity.md`)

Engine text (hook / thought / takeover): the larger size lands exactly on all three paths, with auto-fit still
protecting the safe zone. Line captions: exact on MP4/medium; on raw, advise the in-app size if it is the
caption being punched.

## Finish

Hand off to **glow**.
