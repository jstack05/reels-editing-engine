# hush: dial an element down (quieter)

Load `craft-floor.md` and `scale.md` first. `hush` makes something quieter: smaller, calmer, less dominant.
Usually per element (`/studio hush hook` = a smaller hook that takes fewer lines). It is the creator's opt-in
way to bring one thing down. It is never an automatic shrink.

## What it does

- **Targets one role** (hook, caption, takeover, thought) and steps its size or presence DOWN, in the pack's
  relative terms (a smaller multiplier over the role's base, see `scale.md`). A quieter hook naturally wraps
  to fewer lines, which is the most common reason to reach for it.
- Holds the hierarchy: hushing the hook should not drop it below the caption. The hook can get quieter and
  still lead. If a hush would invert the order, stop at the point where the order still reads.
- Holds the floor: quieter never means unreadable or out of the safe zone.

## The move

Bring the target down one comfortable step, look, and stop when it feels right. This is a feeling call, so
one step at a time, not a leap. The creator says "quieter" and you dial until it sits back into place.

## Per path (from `fidelity.md`)

Engine text (hook / thought / takeover): the smaller size lands exactly on all three paths. Line captions:
exact on MP4/medium; on raw, advise the in-app size if it is the caption being hushed.

## Finish

Hand off to **glow**.
