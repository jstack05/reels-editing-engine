# Logos

This folder is for brand marks you want to appear on screen: your own, and any product or tool you name
in a reel and have the right to show.

What works best:

- **PNG with a transparent background.** A logo on a white square will look like a white square.
- **One mark per file, named for what it is** — `yourbrand-icon.png`, `yourbrand-wordmark.png`. A graphic
  asks for a file by name, so a folder of `logo1.png`, `logo2.png` costs you time later.
- **Drop the full-size version.** Graphics scale a mark down cleanly and scale it up badly.

A note on the ones that are not yours: only add a mark you have the right to use, and let it keep its real
color rather than recoloring it to match your style pack. A logo people recognize is the one thing on
screen that should look like itself.

Ships empty on purpose. Nothing here is required to build a reel.
